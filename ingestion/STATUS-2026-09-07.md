## Repeat the audit

```sh
cd /root/jailmap
docker compose run --rm --no-deps -T \
  --volume /root/jailmap/backend:/app/backend:ro \
  api python -m backend.audit_geography
```

The audit reads directory metadata only, emits JSON, and exits nonzero when a
check fails. It does not access inmate records or modify the database.
